# 📦 Cache Service

`Cache Service` — микросервис, отвечающий за кэширование данных о объявлениях в Redis, получаемых из Kafka. После успешного кэширования отправляется сигнал в Kafka, что данные готовы к использованию.

---

- Получает `AdvertisementDTO` из Kafka-топика `cache-advertisement`.
- Кэширует объект в Redis с TTL 1500 секунд.
- Отправляет сообщение в Kafka (`cache-ready`), сигнализируя, что данные готовы.
