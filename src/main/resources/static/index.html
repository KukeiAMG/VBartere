Чат сервис

Руководство пользователя

1. Начало работы

Для начала работы с чатом необходимо:

  • Иметь действующий JWT токен (должен быть сохранен в браузере)
  • Токен должен содержать ID пользователя

2. Создание чата

Чтобы создать новый чат:

  1. Введите ID пользователя, с которым хотите начать чат
  2. Нажмите кнопку "Создать чат"

3. Отправка сообщений

Для отправки сообщения:

  1. Выберите чат из списка
  2. Введите текст сообщения в поле ввода
  3. Нажмите кнопку "Отправить" или клавишу Enter

4. Просмотр истории

История сообщений загружается автоматически при открытии чата.

5. Закрытие чата

Чтобы закрыть текущий чат, нажмите кнопку "Закрыть чат".

6. Статус подключения

В верхней части страницы отображается статус подключения к серверу:

  • Зеленый - успешное подключение
  • Красный - ошибка подключения
